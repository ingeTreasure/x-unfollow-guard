# 2.0 设计规范

参考：`popup-concept.png`（Image Gen 全屏设计）。实现为 440 CSS px 宽的 Chrome 弹窗，窄窗 320–380 px 自适应；浏览器弹窗高度由 Chrome 控制，超出时正常滚动。

- 背景 #ffffff，正文 #142525，次要文字 #718080，分隔线 #e5eceb，强调色 #087f75，统计背景 #edf7f6，危险操作 #b93842。
- 24 px 外边距（实现为顶部 24、水平 22 px），8 px 圆角；开放分区、细分隔线，无卡片嵌套和渐变。
- 系统中文字体；标题 23 px，分区 15 px，正文/按钮 12–13 px，统计数字 25 px。
- 新 Logo：盾牌与双向连接符，代表关注关系的保护；生产素材 `icons/logo.png`，16/32/48/128 px 扩展图标。
- 主屏顺序：品牌 → 三页签 → 账号与关注列表入口 → 三列统计 → 识别状态 → 高亮开关 → 取关参数和动作 → 折叠保护名单 → 本地存储说明。
- 关注页固定文案依照设计图；账号、数字和状态由实际数据替换。未连接时显示明确提示，统计未知显示破折号；不得填演示数据。
- 同步记录和设置为必要的功能延伸，沿用相同分隔线、字号、控件和间距系统；确认对话框为危险动作新增的原生交互。
- 交互：页签和键盘切换、保留参数、动态保护名单、取关二次确认/停止、本地 Key 保存与清除、同步历史和待核实保护。
- Logo 由内置 Image Gen 生成；提示词为：提取参考中的青绿色盾牌，白色交错折线表达连接和确认，透明背景，小尺寸清晰，无文字。UI 概念提示见本文件的布局、配色与文案约束。
